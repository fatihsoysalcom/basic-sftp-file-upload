# Basic SFTP File Upload

This Python script demonstrates a basic file upload to an SFTP server using the `pysftp` library. It connects to a specified SFTP host, uploads a local file to a remote path, and includes basic error handling.

## Language

`python`

## How to Run

1. Install the `pysftp` library: `pip install pysftp`
2. Replace placeholder SFTP connection details and file paths in the script.
3. Run the script: `python sftp_upload.py`
